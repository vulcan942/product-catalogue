# Product scope

- Build only what `product.md` describes: home, category, search, product page, enquiry.
- Do not add carts, checkout, accounts, admin tools or payments.
- If a requirement is unclear, pick the simplest reasonable reading and write it down as an assumption in `DECISIONS.md`. Do not stop to ask.
- If you drop or simplify a requirement, record what and why in `DECISIONS.md`.
- Do not add features, endpoints or config "for later" that no current requirement uses.
