# AI usage log

Keep `AI_USAGE.md` up to date as work happens, not at the end.

- Record the tools and models used.
- Record 3 to 5 prompts or moments that shaped the solution.
- Record each time AI output was wrong, and how it was caught.
- Record time spent, split across planning, building, testing and reviewing.
- Only the user writes the time-spent figures. Do not estimate them.
